# ParcelTrack Lite

ParcelTrack-Lite is a web-based parcel tracking and management system developed as a university group project. It allows users to manage parcels and track delivery status through a simple and secure platform.

## Features

- User registration and login
- Parcel management and tracking
- Role-based access control
- Secure password hashing and validation
- Protection against SQL injection and Cross-Site Scripting (XSS)

## Technologies Used

- Python – Backend API
- PHP – Web interface
- SQLite – Database
- GitHub Actions – Automated testing
- Pytest – Security and functional testing

## Getting Started

1. Clone this repository.
2. Install the required dependencies using `pip install -r requirements.txt`.
3. Create a `.env` file based on `.env.example`.
4. Configure the environment variables.
5. Start the Python backend and PHP web server.

## Security

Sensitive information and secret keys must be stored in local `.env` files and must not be committed to GitHub.
